Frequently Asked Questions

1. Why can’t I connect Strava?

Please make sure you have entered a valid Strava Client ID and Client Secret on the Settings page before starting authorization.

2. Why can’t I sync workout data?

Please check whether the corresponding account has been configured correctly, whether network access is available, and whether the source platform account is still valid.

3. Why can’t I generate the heatmap?

The heatmap feature requires a one-time in-app purchase to unlock. After unlocking, you can continue loading route data and generating heatmaps permanently on supported versions.

4. Why can’t I save the heatmap to Photos?

Please make sure the app has permission to add images to your photo library. If permission was denied previously, you can enable it in the system settings.

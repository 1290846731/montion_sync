二、我们如何使用收集的信息

所有信息的使用严格服务于「科学减脂」核心目的，具体场景如下：

1. 卡路里消耗计算与展示

  • 通过 CalorieAggregateService 统一计算每日总消耗：静息能量（三级回退：健康槽实测 Basal → 用户 Profile 手动 → 30天静坐均值）+ 活动能量（Workout 与 Active Energy 叠加去重，防止双倍计算）
  • 首页仪表盘展示：7天日均消耗、运动时长/次数/距离多维统计、运动日历热力图
  • 所有时间计算统一按北京时间（UTC+8）零点归一化，防止时区偏移导致数据归属错误

2. AI 个性化减脂方案生成

  • 将用户 Profile（身高、体重、年龄、性别、目标）+ 近30天运动历史 + 饮食记录 + 当日消耗汇总为结构化上下文
  • 通过大语言模型（LLM）生成：个性化饮食方案、本周训练计划、饮食搭配建议、月度身体复盘与下月计划
  • AI 工具结构化调用：estimate_daily_calories（获取每日卡路里明细）、get_meal_records（查询已记录饮食）

3. 身体数据趋势分析

  • 体脂率、肌肉量、静息心率变化趋势曲线图展示
  • AI 体型评估：结合体脂/体重变化给出减脂/增肌阶段建议
  • VO2 Max 最大摄氧量、训练负荷趋势分析，预防过度训练

4. 饮食记录与热量缺口管理

  • AI 拍照识别：上传食物图片 → AI 识别食物种类 → 估算卡路里与宏量元素 → 用户气泡确认后入记录
  • 按餐段色块（早餐橙/午餐绿/下午茶紫/晚餐青/夜宵红）区分展示，今日汇总卡片显示当日摄入与剩余配额
  • 摄入与消耗对冲计算当日热量缺口，支撑减脂进度跟踪

5. 实时运动数据面板（锻炼中）

  • 锻炼过程中实时展示：当前心率、配速、累计距离、累计卡路里、运动时长
  • 运动强度语音播报提醒（如心率进入过高区间时提示降速）

三、信息的存储与安全

🛡️ 本地优先存储策略：绝大多数数据存储于设备本地，不上传第三方服务器

1. 存储方式：高性能 MMKV

所有结构化数据（用户 Profile、绑定状态、饮食记录元数据、运动缓存索引）采用腾讯开源的 MMKV 高性能本地键值存储方案，存储于应用沙盒内（iOS：Application Support目录；Android：App私有目录），非Root/越狱设备无法访问。

2. 缓存策略

  • 7天/30天卡路里聚合结果：5分钟内存缓存，过期自动失效
  • 30天静坐均值 Basal：24小时缓存
  • 运动记录列表缓存：最多200条，超出自动裁剪
  • 食物图片：存储于应用沙盒 Documents 目录，绑定记录 ID

3. 第三方数据传输安全

  • 健康平台 API：华为 Health Kit、Apple HealthKit 均为设备端授权后读取，Apple Health 数据通过原生串行队列（_serialize）访问，防止并发崩溃与数据竞争
  • Strava / Garmin OAuth：仅在用户完成 OAuth 授权后获取 Access Token，Token 同样存储于 MMKV
  • AI 模型 API：通过 HTTPS TLS 1.2+ 加密通道传输请求上下文，仅传递计算必需字段，不携带设备无关标识符

4. 数据出境说明

本应用服务范围为中国大陆及亚太地区。若所使用的 AI 服务商或第三方运动平台服务器位于境外，相关数据传输将遵循对应平台的跨境传输合规条款，且始终限定于减脂计算最小必要范围。

四、第三方服务接入清单

本应用通过 Adapter 抽象模式接入以下第三方服务，各服务均有独立的隐私政策：

  • 华为健康（Health Kit）：读取热量、活动小时、锻炼记录概要/详情、体脂、心率、运动能力、一月历史数据、实时锻炼数据 — iOS亚太/Android免登录授权
  • Apple HealthKit：读取 Basal Energy、Active Energy、Workout、心率、体脂、体重、睡眠、步数、距离
  • Strava API v3：通过 OAuth 读取 Athlete 运动记录与流数据（心率、配速、功率 Stream）
  • Garmin Connect：通过官方 OAuth 接入活动记录
  • 大语言模型（LLM）服务商：接收结构化上下文生成减脂方案与食物识别结果
  • image_picker（系统相册/相机）：仅在用户主动发起「拍照识别食物」时调用，图片不自动上传

五、您的权利与控制

作为数据主体，您享有以下完整权利，均可通过本应用「我的」页面自助完成：

1. 知情与撤回授权

  • 解绑健康槽：我的 → 设备绑定 → 解除 Apple Health / 华为健康绑定
  • 解绑运动槽：我的 → 设备绑定 → 解除 Strava / Garmin 绑定，对应 Access Token 立即从 MMKV 清除
  • iOS 系统可在「设置 → 隐私与安全性 → 健康」中随时撤销本 App 对 HealthKit 的读取权限
  • 华为健康可在「运动健康 App → 隐私 → 数据共享与授权」中撤回授权

2. 数据访问、更正与删除

  • 查询访问：首页查看运动/消耗数据；饮食页滚动浏览历史记录；我的 → 个人资料查看基础 Profile
  • 更正编辑：个人资料字段可随时修改（身高、体重、目标体重、体脂率、每日缺口、BMR）；单条饮食记录支持编辑与修改餐段
  • 删除记录：饮食记录左滑可删除单条；我的 → 清除本地缓存可清空全部应用数据（含MMKV存储、缓存图片、运动记录索引）

3. 关闭 AI 图片识别

您可仅使用手动饮食录入功能，不使用拍照识别，此时应用不会调用相机/相册权限，亦不上传任何图片。

六、未成年人保护

本应用主要服务于18周岁以上具有完全民事行为能力的成年人减脂管理。若您为未成年人，请在监护人陪同下阅读本政策；我们不主动采集未满14周岁儿童的任何个人信息。

七、Cookie 与同类技术

本应用为原生 Flutter App，不使用 Cookie 跟踪。登录授权采用 OAuth 标准流程，仅存储必要 Token 于本地 MMKV。

八、政策更新

当业务功能发生重大变化（如新增第三方数据接入、使用目的变更）时，我们会在应用内以弹窗或公告方式通知您，并更新本页顶部的「生效日期」。重大变更需重新取得您的明示同意。
